# Note-type classifier — results

Generated by `train.py` (seed 0). 40 notes, 10 journal, 10 meeting, 10 project, 10 reference. 5-fold stratified cross-validation: each note is predicted by a model trained without it.

| System | Accuracy | Macro F1 |
|---|---|---|
| Majority class (always the most common label) | 0.250 | 0.100 |
| Hand-written keyword rule | 0.875 | 0.875 |
| TF-IDF + logistic regression | 0.625 | 0.618 |
| TF-IDF + logistic regression, dates removed | 0.600 | 0.593 |

Accuracy per fold (8 notes each): 0.625, 0.625, 0.625, 0.625, 0.625
