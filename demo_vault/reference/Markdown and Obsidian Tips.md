# Markdown and Obsidian Tips

## Links

Wrap a note name in double square brackets to link it, for example [[Git Cheatsheet|my git notes]]. A link to a note that does not exist yet is shown faded.

## Tasks

A task is a list item with a box. In a code block it is only an example and should not count:

```markdown
- [ ] this is example syntax, not a real task
#not-a-real-tag
```

## Tags

Tags start with a hash, like #obsidian. A language name such as C# is not a tag.

## Habit

I should review the week's notes every Sunday evening.
